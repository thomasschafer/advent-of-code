# Advent of Code solutions

My [Advent of Code](https://adventofcode.com/) solutions.

## Running with Workshop

The solutions are laid out for [Workshop](https://github.com/thomasschafer/workshop):

```sh
workshop run 2024 1                    # run on your puzzle input
workshop run 2024 1 --sample           # run on the example chosen in Workshop, checking its answers
workshop run 2024 1 --sample --part 2  # run on part 2's example
eval "$(workshop env)"                 # set up the shell, and an editor started from it, to find the helpers and packages
```
